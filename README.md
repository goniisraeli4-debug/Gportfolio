# Portfolio

A minimal graphic design portfolio. Plain HTML, CSS and JavaScript — no build step, no dependencies. Set in [Miriam Libre](https://fonts.google.com/specimen/Miriam+Libre), self-hosted from `fonts/`.

## Run it locally

```bash
cd "path/to/this/folder"
python3 -m http.server 8000
```

Then open <http://localhost:8000>. A local server is required — opening `index.html` straight from Finder blocks the fonts and scripts.

## How it is put together

| Path | What it does |
| --- | --- |
| `index.html` | Home — opening → 5 featured projects (horizontal while scrolling) → footer |
| `about.html` | Studio page: bio, services, clients, contact |
| `project.html` | One template that renders any project, chosen by `?p=slug` |
| `js/data.js` | **All site content lives here** |
| `js/site.js` | Header, menu overlay, page transitions, reveals, footer |
| `js/home.js` | Home page rendering and the cursor-following preview |
| `js/project.js` | Builds project panels and drives the horizontal scrolling |
| `css/` | `base` (tokens, type), `nav`, `home`, `project`, `about` |
| `assets/work/` | Placeholder artwork — replace with your own images |
| `fonts/` | Miriam Libre, variable plus static weights, and its licence |

## Editing content

Everything is in `js/data.js`. Nothing else needs touching for day-to-day updates.

**Your details** — edit the `SITE` object: name, role, location, email, phone, the home page `statement`, the `about` copy, `services`, `clients` and `socials`.

**Add a project** — append an object to the `PROJECTS` array. It appears on the home page, in the menu, and gets its own page automatically at `project.html?p=your-slug`.

```js
{
  slug: "new-project",          // becomes the URL
  title: "New Project",
  client: "Client Name",
  year: "2026",
  discipline: "Brand Identity",
  summary: "One or two sentences shown on the opening panel.",
  cover: "assets/work/01.svg",  // used in the index and hover preview
  credits: [{ role: "Design", name: "Your Name" }],
  slides: [ /* the horizontal panels, see below */ ]
}
```

**Panel types** for `slides`, laid out left to right in the order you write them. An opening panel and a closing panel with credits and the next project are added for you.

```js
{ kind: "image", src: "assets/work/01.svg", caption: "Caption", size: "wide" }
{ kind: "text",  heading: "A short heading", body: ["First paragraph.", "Second."] }
{ kind: "quote", text: "A line worth pulling out.", source: "Who said it" }
{ kind: "stack", items: [{ src: "…", caption: "…" }, { src: "…", caption: "…" }] }
```

`size` sets how tall an image sits: `std`, `wide`, `tall`, or `full` for an edge-to-edge bleed. Panel width follows each image's own proportions, so mixing portrait and landscape creates the rhythm of the page.

## Using your own images

Drop files into `assets/work/` and point `src` and `cover` at them. Export at roughly 2400 px on the long edge and save as JPG or WebP; the panels scale from there. The included `.svg` files are stand-ins generated by `gen_placeholders.py` — delete that script and the SVGs once your own work is in.

## Moving around a project page

Trackpad and mouse wheel scroll sideways, and so do click-and-drag, arrow keys, Page Up/Down, Home/End and swiping on touch. The bar along the bottom shows how far through you are.

## Changing the look

The design is controlled by custom properties at the top of `css/base.css`: `--paper`, `--ink`, `--accent`, the `--step-*` type scale, and `--edge` / `--bar` for page margins. Adjusting those few values restyles the whole site.

## Publishing

It is a static site, so any host works. Drag the folder onto [Netlify Drop](https://app.netlify.com/drop), or push to GitHub and turn on Pages in the repository settings.
